# 📝 نحوه اجرا

### 1. دانلود پوشه `Optimization_Path_Visualizer`

### 2. نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### 3. فایل `main.py` را اجرا کنید.

```bash
python main.py
```
